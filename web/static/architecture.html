1. System & Render Free-Tier Architecture

Single Container • ≤ 512 MB RAM

Clean separation between the accessible FastAPI web tier, input/output guardrails, async orchestrator, JSON-RPC stdio Model Context Protocol layer, Hybrid RAG vector/BM25 retrieval, and synthetic HR stores.

2. Hybrid RAG Ingestion & Query Pipeline

Top-k = 5 • RRF (k=60)

Heading-aware ingestion across four file formats feeds parallel dense vector search (FAISS cosine) and sparse BM25 lexical scoring, protected by a Zero-Match RRF pollution gate and sentence-level snippet extraction.
