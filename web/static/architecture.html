Hybrid RAG ingestion & query pipeline

Every chunk is embedded densely with Gemini (or hash fallback offline) and indexed sparsely with BM25, fused at query time via Reciprocal Rank Fusion.

FAISS + BM25 + RRF
A. Build & background indexing · Dockerfile prebuilds hash index, Gemini upgrades in background
STEP 01
12 Policy Docs
4 formats (HTML, PDF, MD, TXT) · 8,907 words
STEP 02
Format Parsers
Headings merged; ~350w chunks, 60w overlap
STEP 03
Metadata Prefix
Prepend doc_id, title & section_path → 117 chunks
STEP 04
Dual Indexer
768-d dense vectors + stopword BM25 matrix
READY
IndexFlatIP + chunks.db
Persisted SQLite & FAISS; hot-swapped atomically
B. Online retrieval · Executed via search_policy_documents MCP tool
STEP 01
MCP Tool Call
search_policy_documents (query, top_k=5, filter)
STEP 02
Dual + Synonym Index
HR synonym expansion → cosine + BM25 ranks
STEP 03
Fuse RRF (k=60)
Reciprocal Rank Fusion + exact POL-ID boost
STEP 04
Threshold Gate
RRF >= 0.008 & floor → else flag insufficient evidence
RESPONSE
Cited Output
Sentence snippet extraction + strict claim citations
